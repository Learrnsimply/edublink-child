## رحلة عمر — الهيكل العام

**مبدأ التصنيف:** نصنّف بـ "عمر بيعمل بيها إيه" مش بالموضوع — فـ 10 أنواع رسائل = 6 مسارات.

```
رسالة واتساب جاية
   │
   └─ Stage 0: التصنيف (Triage) — عمر يفهم النية
        ├─ 🛒 (A) مبيعات/استفسار   → يرد بنفسه من الـ KB → يقنع → يوجّه للدفع
        ├─ 🛠️ (B) دعم/مشاكل        → تعريف العميل → تشخيص → حل أو تصعيد
        ├─ 🌍 (C) دفع برّه مصر      → script الكروت الأجنبية → يساعد ثم يصعّد
        ├─ 🎓 (D) لأحمد شخصياً      → يجمع التفاصيل بأدب → إيميل لأحمد+عمر للمتابعة ✅
        ├─ 📚 (E) سؤال برمجي تقني   → يوجّه بلطف (درس/أحمد/المجتمع) — مايجاوبش كود ✅
        └─ 🚨 (F) حساس/غاضب/استرجاع → تصعيد بشري فوري
   │
   └─ أداة شاملة: 🔔 الإنذار — أي مشكلة حقيقية → إيميل + واتساب لأحمد وعمر + "وصّلت الفريق"
```

**تفصيل الأنواع داخل كل بوكس:**
- **A** مبيعات: سعر · الكورس فيه إيه · يصلح لمستواي · الباقات · إزاي آخد شهادة · بيغطّي موضوع X.
- **B** دعم: الموقع مش فاتح (F1) · دفعت وملقتش الكورس (F2) · فشل دفع · الشهادة مش ظاهرة.
- **D** لأحمد: دروس خصوصي/private · تعاونات · إعلانات · طلب كورس لسه ماعملوش (feature request).
- **E** برمجي: "الكود ده ليه مش شغّال؟" / "إزاي أحل التمرين؟" — قرار النطاق مفتوح.

## الـ Flows المتحددة

### 🔧 F1 — شكوى "الموقع/الحصص مش بتفتح" (site_access bug) — ✅ متحدد 2026-06-03
1. **عمر يجمع (شرط أساسي):** سكرين شوت للمشكلة + إيميل العميل.
2. **عمر يطمّن:** "هتتحل خلال اليوم، وهنبلغك فوراً أول ما تتصلح."
3. **إنذار فوري** (إيميل + واتساب) لأحمد + عمر، مرفق: السكرين + إيميل العميل + ملخص المشكلة.
4. **الحل بشري:** أحمد/عمر يدخلوا يصلّحوها بنفسهم.
5. **تأكيد للعميل:** إيميل إن المشكلة اتحلت (بعد الحل).

**حالات حافة (مقترحات مبدئية — للتأكيد):**
- العميل مبعتش سكرين → عمر يطلبها مرة كمان بلطف؛ لو معندوش، يصعّد بالإيميل بس مع ملاحظة "بدون سكرين".
- "خلال اليوم" = ضمن ساعات العمل (✅ السبت→الخميس 10ص–6م).
- **مفتوح:** إيميل "اتحلت" بشري بالكامل، ولا عمر يبعته أوتوماتيك أول ما إنتوا تأكّدوا الحل؟

### 🎓 F-D — العروض الخاصة لأحمد (private/تعاون/إعلان/طلب كورس) — ✅ متحدد 2026-06-03
1. عمر **يجمع التفاصيل** بأدب (مين، عايز إيه بالظبط، أي تفاصيل مهمة) — **من غير ما يوافق/يرفض/يحدّد سعر**.
2. عمر يبعت **إيميل لأحمد + عمر** بالتفاصيل (تواصل خاص لأحمد عادل، عشان يتابعوا).
3. عمر يقول للعميل: "وصّلت طلبك لأحمد، وهيتواصل معاك."

### 📚 F-E — الأسئلة البرمجية التقنية — ✅ متحدد 2026-06-03
- عمر **مايجاوبش كود** (خطر التضليل + بيحطّه مكان أحمد + بياكل من قيمة الكورس). يوجّه بلطف: شوف الدرس/الوحدة ذات الصلة (من الـ KB) + اسأل أحمد/مجتمع الطلاب. (ممكن نضيف مساعدة خفيفة لاحقاً بعد ما نثبّت الأساس.)

### 🛒 F-A — المبيعات / استفسار قبل الشراء — ✅ متحدد 2026-06-03
**المبدأ:** عمر افتراضياً **بيساعد مباشرة** — مايستجوبش العميل. مايقفزش خطوة لو المعلومة موجودة. السعر من الـ KB بس.
- **A-direct (الافتراضي):** لو العميل عارف عايز إيه ("جافا بكام؟") → يرد مباشرة + يوجّهه للدفع فوراً (A4).
- **A1+A2 (شرطي — بس لو العميل طلب ترشيح / "مش عارف أبدأ بإيه"):** يفهم الهدف/المستوى → يرشّح الكورس/الباقة من الـ KB + social proof (تقييم + عدد طلاب) + **upsell الباقة** لو منطقي.
- **A3 (اعتراضات):** يرد من الـ KB (استرداد 7 أيام · وصول مدى الحياة · دفعة واحدة مفيش اشتراك · مبتدئ مناسب 100% · التقييمات · الشهادة). → **التحسين بعد شهر تجربة بداتا حقيقية** (نمط tactics-learning زي rspaac).
- **A4 (توجيه للدفع):** لينك الكورس/المنتج + طمأنة (تلقائي بعد الدفع، أي مشكلة → واتساب).
- **A5 (متردد وماقفلش):** يسجّله في **Mautic** (`mautic_upsert`، tag `whatsapp-lead` + `course_interest:<course>`) → إيميل متابعة لاحق، **صفر ضغط**.

### 🔔 أداة الإنذار/التصعيد (cross-cutting) — ✅ متحدد 2026-06-03
نوعان:
- **🚨 مشكلة (support):** موقع (F1) · فشل دفع · access · شهادة · غاضب/استرجاع → رسالة العميل: *"وصّلت الفريق، هتتحل وهنبلغك فوراً"*.
- **🎓 تواصل لأحمد:** private · تعاون · إعلان · طلب كورس → رسالة العميل: *"وصّلت طلبك لأحمد، هيتواصل معاك"*.

كل إنذار → **إيميل + واتساب لأحمد + عمر**، بيحتوي: 🏷️ النوع + الأولوية (غاضب=🔴) · 👤 اسم العميل + تليفونه + إيميله · 📝 ملخص (عمر بيلخّص) · 📎 السكرين (لو موجود) + آخر رسائل المحادثة (context).

### 🚨 F5 — طلب استرجاع / عميل غاضب — ✅ متحدد 2026-06-03
**مبدأ:** عمر **عمره ما يوافق/يرفض استرجاع بنفسه** (قرار فلوس = بشري). تعاطف أول، مايجادلش.
- **F5a — طلب استرجاع:** (1) تعاطف. (2) يشرح السياسة **حقيقةً** من الـ KB: استرداد خلال 7 أيام لو شاف <20% · العطل التقني الموثّق = استرداد كامل بغض النظر · الكتب بعد التحميل = مفيش. (3) يجمع: رقم الأوردر + إيميل + السبب. (4) **تصعيد 🚨** — القرار النهائي بشري (حتى لو عدّى 7 أيام، مايرفضش صريح — "الفريق هيراجع حالتك" عشان استثناء العطل التقني وارد). (5) رسالة: "وصّلت طلبك للفريق، هيراجعوه ويردوا عليك."
- **F5b — عميل غاضب (من غير طلب استرجاع):** (1) يهدّي بتعاطف ("آسف إن ده حصل، أنا معاك"). (2) مايجادلش، يجمع المشكلة. (3) **تصعيد فوري 🔴 عاجل**. (4) رسالة: "وصّلت الفريق، هيتواصلوا معاك بأسرع وقت."

### 🎓 F2 — "دفعت وملقتش الكورس" (course access) — ✅ متحدد 2026-06-04 (بإجابة أحمد)
**المبدأ:** عمر بيحل بنفسه بالخطوات الأول (أغلب الحالات = العميل مش عارف يلاقي الكورس)، يصعّد بس لو الخطوات فشلت.
1. **تأكيد تسجيل الدخول:** "اتأكد إنك مسجّل دخول بنفس الإيميل اللي دفعت بيه" → https://learrnsimply.com/dashboard/
2. **مكان الكورسات:** يوجّهه لصفحة الكورسات المسجّلة → https://learrnsimply.com/dashboard/enrolled-courses/
3. **نسي الباسورد:** من الـ dashboard → إعادة تعيين → بيوصله إيميل على الإيميل المسجّل.
4. **لو لسه مش ظاهر بعد الخطوات** (دفع بإيميل مختلف / تفعيل يدوي ماتمّش) → **يجمع: الإيميل المسجّل + رقم الأوردر/إثبات الدفع** → **تصعيد 🚨** لتفعيل يدوي بشري.
> مرجع الـ KB: §10.2.

### 🌍 F-C — الدفع لبرّه مصر / فشل البطاقة — ✅ متحدد 2026-06-04 (بإجابة أحمد)
**المبدأ:** يساعد بالبدائل الحقيقية الأول، يصعّد للتفعيل اليدوي.
1. **بطاقة أجنبية رفضت:** ينصح ببطاقة تدعم المعاملات الدولية (Visa/Master). + لو PayPal اتفعّل → يعرضه (🟡 مؤجّل لقرار Omar).
2. **بديل مضمون (مصر + تحويل):** الدفع اليدوي — فودافون كاش `01030127228` / إنستاباي `01102681074` → العميل يحوّل + يبعت الإثبات + **الإيميل المسجّل** → تفعيل يدوي.
3. **اليمن/سوريا (حظر دفعات):** يوضّح إنهم يقدروا يخلّوا حد من داخل مصر يدفع بالتحويل ويتفعّل الكورس على إيميلهم.
4. ⚠️ **شرط دايم:** لازم العميل يعمل حساب/إيميل على المنصة الأول.
5. **فشل دفع متكرر** → **تصعيد 🚨** (إنذار لأحمد+عمر).
> مرجع الـ KB: §6.1b + §6.2.
