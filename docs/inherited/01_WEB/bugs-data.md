**الأثر:** في كتير من الدول (ومنها مصر) القانون بيتطلب إن الشروط والأحكام تظهر في صفحة الـ checkout. غيابها ممكن يأثر على الثقة وعلى payment gateway compliance.

**الإصلاح:** روح WooCommerce → Settings → Advanced → اختار ID 38439 كصفحة رسمية للشروط والأحكام. احذف أو حول للـ draft الصفحة 22681 المكررة.

**الخطورة:** 🔴 Critical  
**المكان:** WooCommerce → Settings → Advanced → الشروط والأحكام
