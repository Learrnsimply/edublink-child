- **العملة:** الجنيه المصري (EGP). الموقع متظبط على مصر.

- **طريقة الطلب:** تواصل عبر إيميل أو واتساب مع **رقم الطلب + السبب**.

### 7.2 الشروط والأحكام (ملخص)
- الدفع **نهائي** عند نجاح المعاملة · تأكيد بالإيميل · الوصول فور التأكيد من لوحة الحساب · الأسعار شاملة الضرائب.
- المحتوى ملكية حصرية — **ممنوع** إعادة النشر/المشاركة/التسجيل/الاستخدام التجاري · يجوز اقتباس قصير أكاديمي بذكر المصدر.
- ممنوع: محتوى مسيء · اختراق · انتحال · Scraping آلي. (مخالفة = تعليق/إنهاء الحساب.)
- إخلاء مسؤولية: مفيش ضمان توافر دائم/نتائج وظيفية بعينها.
- ✅ **القانون الحاكم: الإمارات / محاكم دبي — مقصود** (أكّد أحمد 2026-06-04: "مقصود لزيادة ثقة العملاء"، مش خطأ قالب). الـ agent يتعامل معاه كسياسة رسمية.

### 7.3 سياسة الخصوصية (ملخص)
- بيجمع: اسم/إيميل، بيانات الدفع (تُعالج عبر بوابات معتمدة، **مش بتتخزّن**)، رسائل الدعم، IP/متصفح، تقدّم الكورسات.
- **مش بيبيع البيانات.** بيشاركها فقط مع مزودي الخدمة (دفع/إيميل/استضافة) أو لالتزام قانوني.
- أمان: HTTPS/TLS · بطاقات الدفع PCI-DSS مش بتمر بخوادمهم · وصول مقيّد.
- الاحتفاظ: حذف البيانات التعريفية خلال **30 يوم** بعد حذف الحساب · بيانات مالية تُحفظ أطول قانونياً.
- الحقوق: وصول/تصحيح/حذف/اعتراض/إلغاء اشتراك. **للأعمار 16+.**
