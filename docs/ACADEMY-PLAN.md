# خطة أكاديمية اتعلم ببساطة

> ٣ سبتمبر ٢٠٢٦. الهدف اللي حدده أحمد: **تحويل المنصة لأكاديمية** فيها كورسات برمجة
> وكورسات AI، شكلها جذاب، وتحس إنها كيان مؤسسي، مع إصلاح الأخطاء.
>
> نسخة مقروءة منشورة كـ Artifact كمان.

## الفكرة الأساسية

«شكلها جذاب» و«تكون فعلاً أكاديمية» **هدف واحد مش اتنين**. الأكاديمية بتبان
أكاديمية من **بنيتها** مش من ألوانها. أحسن تصميم فوق قايمة كورسات مفكوكة
بيطلّع قايمة كورسات جميلة — مش أكاديمية.

| الموقع دلوقتي | الأكاديمية |
|---|---|
| ٦ كورسات في شبكة، مفيش علاقة بينهم | أقسام، وكل قسم مسار بمستويات |
| «نبذة عني» قسم بـ٢.٢ شاشة | المؤسِّس ورا كيان مش هو الكيان |
| القائمة: الرئيسية · الدورات · نبذة عنّي | القائمة = الأقسام |
| البطل هو المدرّس | البطل هو رحلة الطالب |

## هيكل الأكاديمية — متفق عليه

مستخرج من الكتالوج الموجود، مش تصنيف مخترع.

```
قسم الأساسيات        (٤ كورسات — يطابق منهج كليات الحاسبات المصرية)
   Java Basics → Java OOP → Data Structures ١ → Data Structures ٢

قسم تطوير التطبيقات
   أساسيات Dart → [Flutter — لسه]

قسم الذكاء الاصطناعي  (الجديد — وهو اللي القناة بتبني جمهوره)
   Vibe Coding → [كورس AI — تحت التنفيذ]

البوابة المجانية
   مشاريع بايثون للمبتدئين
```

## المراحل — بالترتيب ده تحديدًا

### ٠ · افتح الداتا اللي عندك · نص يوم
**GA4 وMicrosoft Clarity مركّبين بالفعل ومحدش فتحهم.** مش محتاج تركيب، محتاج قراءة.
- GA4: أعلى ٥ صفحات دخول · نسبة ترافيك يوتيوب · موبايل/ديسكتوب · مصدر الشرا
- Clarity: خرائط حرارية + تسجيلات جلسات للرئيسية وصفحة الكورس
- سجّل الأرقام في `BUSINESS-CONTEXT.md`

### ١ · بنية الأكاديمية · ٣–٤ أيام
الأساس. القائمة والصفحات والهوية كلهم معلّقين عليه. أغلبه شغل بيانات مش كود.
- الأقسام كتصنيف حقيقي في Tutor LMS (`course-category`)
- كل كورس: قسم · مستوى · متطلب سابق · مخرج تعليمي
- صفحات أقسام جديدة (`/departments/ai/` …) — **مش موجودة حاليًا**
- القائمة: «الدورات» تبقى **الأقسام**
- ترتيب الكورسات بالمستوى مش بالتاريخ

### ٢ · دليل الهوية · ٣–٤ أيام
النص التقني معمول (٦٣ توكن، تغطية ٨٩٪). الناقص النص البشري.
- **الموقف** — الجملة موجودة عندك: «مش بحاول أثبت إني عارف — بحاول إنك أنت تفهم»
- **الجمهورين** — طلبة جامعة (أساسيات) + جمهور أوسع (AI). التحدي: قسمين في كيان واحد
- **النبرة** — متسقة أصلًا؛ محتاجة توثيق + إصلاح تنافر: الجسم مصري والأزرار فصحى
- **الشخصية البصرية** — الصور والرسومات (خليط)، ومكونات موحدة
- **اللوجو** — محتاج مصمم بشري

### ٣ · الصفحات بترتيب الترافيك · ١–٢ أسبوع
المبيعات من يوتيوب أورجانيك، والأوصاف بتوصّل لصفحات الكورسات مباشرة.
**فالرئيسية مش ساحة المعركة.**
1. **صفحة الكورس** — كل المبيعات بتنزل هنا. أعلى أولوية
2. **صفحة القسم** — جديدة. هي اللي بتخلي الأكاديمية تبان أكاديمية
3. **الرئيسية** — من ٢٤.٦ شاشة و١٤ قسم لبنية مبنية على الأقسام
4. **أرشيف الكورسات** — يتنظّم بالأقسام

### ٤ · القمع · ٢–٣ أيام
أكبر تسريب: **صفر وسيلة لجمع إيميل في الموقع كله**، وكورس AI تحت التنفيذ.
- قائمة انتظار على `/vibe-coding-course/` — الصفحة دي فيديوهاتك بتوصّل ليها ومفيهاش زرار
- ظبط أوصاف يوتيوب (فيديو Claude بيوصّل لكورس Java) — نص مش كود، ساعة شغل
- ربط تليجرام بالموقع
- تسلسل بعد الشرا

### ٥ · الأخطاء والأداء · ٤–٥ أيام
الأداء جزء من الشكل. ٧٢ CSS + ٧٦ JS + ٢٣ كتلة style inline في الصفحة الواحدة.
- **تناقض Elementor** — ٥ بلجنات بتتحمّل والثيم بيحاول يوقّفها. حلّه بيشيل معظم الملفات **و**معظم الـ٤,٩٦٩ `!important`
- بلجنات ميتة: `astra-sites` · `wp-events-manager` · `yith-quick-view`
- ١,٢٠٠ سطر CSS جوه `functions.php` محقونة في `wp_footer` — مش داخلة كاش ومش شايفة التوكنز
- IDs بالإيد في التوجيه (`9834`, `22662`, `21`, `21744`)
- استعلام مباشر على `asnp_wepb_simple_bundle_items` في محمّل الأصول
- `posts_per_page => -1` في الرئيسية والتعليق بيقول ٦
- ملفات ميتة: `assets/about-me/style.css.tmp` (٩,٠٨٠ سطر) + سكاشن Twig مكررة
- الخصم الدائم على كل كورس (مسألة تسعير مش كود)
